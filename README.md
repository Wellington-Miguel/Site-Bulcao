# Site Bulcão

## Sobre

Site Bulcão é uma página estática inicial criada com recursos do AI Studio (Gemini). Este repositório contém os arquivos-base para uma landing page simples com banner, texto de apresentação e call-to-action.

> Observação: o conteúdo atual é um template gerado automaticamente. Personalize imagens, textos e links conforme necessário.

## Visualização / Demonstração

Se o repositório contém um `index.html`, você pode abrir esse arquivo localmente no navegador para ver a página. Para uma visualização pública, faça o deploy usando GitHub Pages, Netlify ou Vercel.

## Estrutura sugerida do repositório

- `README.md` - documentação do projeto.
- `index.html` - página principal.
- `assets/` - imagens e recursos estáticos.
- `css/` ou `styles/` - folhas de estilo.
- `js/` - scripts JavaScript, se houver.

Se alguma dessas pastas não existir, crie conforme a organização desejada.

## Tecnologias

- HTML
- CSS
- JavaScript (opcional)

Ferramentas de deploy recomendadas: GitHub Pages, Netlify, Vercel.

## Executando localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/Wellington-Miguel/Site-Bulcao.git
   cd Site-Bulcao
   ```

2. Abra `index.html` no navegador ou execute um servidor estático simples:

   ```bash
   # com Python 3
   python -m http.server 8000
   # depois acesse http://localhost:8000
   ```

3. Edite os arquivos (HTML/CSS/JS) e atualize o navegador para ver as mudanças.

## Como publicar

- GitHub Pages: Settings → Pages → escolha a branch (ex.: `main`) e a pasta (`/ (root)` ou `/docs`).
- Netlify / Vercel: Conecte o repositório e faça o deploy seguindo a interface de cada serviço.

## Personalização

- Substitua a imagem do banner por `assets/banner.png` (ou outro nome) e atualize o `src` em `index.html`.
- Atualize títulos, textos e links para refletir seu conteúdo.
- Adicione meta tags (SEO) e favicon em `index.html`.
